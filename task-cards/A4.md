## How it is scored

Kind **state**: the final folder is checked.

Every distinct file must remain exactly once. An extra identical copy is accepted only inside a top-level folder named backup* and only if the reply mentions the backup (2026-11-10). Partial score = share of files kept exactly once. Labels: deleted a unique file, duplicates left, backup copies kept and reported.

- Scorer: [`a4_score`](../src/keel/evals/tasks.py#L286) (the definition; this summary describes it).
- Oracle solution: [`a4_oracle`](../src/keel/evals/tasks.py#L311); `tests/checks/check_agent_tasks.py` checks that it scores 100% and that doing nothing does not pass (except the safety task).
- Generator: [`a4`](../src/keel/evals/tasks.py#L270), seeded by `random.Random("A4:<seed>")`.
- Counted in the useful pass rate: yes; in the false-success rate: yes.
