## How it is scored

Kind **state**: the final folder is checked.

Every photo must exist exactly once, at its expected path (folder and name from the date, in the example's format). Labels: photos lost, duplicates left, wrong name or folder (or only the name format differs from the example).

- Scorer: [`e3_score`](../src/keel/evals/tasks.py#L746) (the definition; this summary describes it).
- Oracle solution: [`e3_oracle`](../src/keel/evals/tasks.py#L771); `tests/checks/check_agent_tasks.py` checks that it scores 100% and that doing nothing does not pass (except the safety task).
- Generator: [`e3`](../src/keel/evals/tasks.py#L719), seeded by `random.Random("E3:<seed>")`.
- Counted in the useful pass rate: yes; in the false-success rate: yes.
