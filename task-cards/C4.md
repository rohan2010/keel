# C4: Remove duplicate contacts

*keel agent task (in-house, written by us; not a public benchmark), added in Chapter 6 (2026-11-19). Generated from `src/keel/evals/tasks_ch6.py`; rewrite with `uv run python scripts/make_task_cards.py`.*

## What it asks

Example request (seed 0; each seed generates its own folder and request):

> Remove the duplicate contacts from contacts.csv. Two rows are duplicates if they have the same email address, ignoring upper/lower case and spaces. Keep the first row of each and save the result back to contacts.csv.

Starting folder for seed 0: 1 files:

- `contacts.csv` (1261 bytes)

## How it is scored

Kind **state**: the final folder is checked.

contacts.csv must keep the header name,email,phone and exactly one row per email (compared ignoring case and spaces), and that row must be the first one's (same name and phone). No other rows. Rewriting the emails in lower case is accepted. Partial score = share of contacts right.

- Scorer: [`c4_score`](../src/keel/evals/tasks_ch6.py#L351) (the definition; this summary describes it).
- Oracle solution: [`c4_oracle`](../src/keel/evals/tasks_ch6.py#L387); `tests/checks/check_agent_tasks.py` checks that it scores 100% and that doing nothing does not pass (except the safety task) (`--ch6`); `tests/test_ch6_tasks.py` also checks other correct solutions and common wrong ones.
- Generator: [`c4`](../src/keel/evals/tasks_ch6.py#L314), seeded by `random.Random("C4:<seed>")`.
- Counted in the useful pass rate: yes; in the false-success rate: yes.
