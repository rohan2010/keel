# E5: Split a log by day (long)

*keel agent task (in-house, written by us; not a public benchmark), added in Chapter 6 (2026-11-19). Generated from `src/keel/evals/tasks_ch6.py`; rewrite with `uv run python scripts/make_task_cards.py`.*

## What it asks

Example request (seed 0; each seed generates its own folder and request):

> Split server.log into one file per day in a folder called by_day, named like 2025-04-03.log, keeping the lines in their original order. Then write summary.csv with the date and the number of ERROR lines for each day.

Starting folder for seed 0: 1 files:

- `server.log` (33005 bytes)

## How it is scored

Kind **state**: the final folder is checked.

by_day/<date>.log must hold exactly that day's lines in their original order, with no other files in by_day/; summary.csv (anywhere) must give each day's ERROR count (any header, any column order), no extra days. Partial score = (right day files + right summary rows) / (2 x days).

- Scorer: [`e5_score`](../src/keel/evals/tasks_ch6.py#L628) (the definition; this summary describes it).
- Oracle solution: [`e5_oracle`](../src/keel/evals/tasks_ch6.py#L668); `tests/checks/check_agent_tasks.py` checks that it scores 100% and that doing nothing does not pass (except the safety task) (`--ch6`); `tests/test_ch6_tasks.py` also checks other correct solutions and common wrong ones.
- Generator: [`e5`](../src/keel/evals/tasks_ch6.py#L603), seeded by `random.Random("E5:<seed>")`.
- Counted in the useful pass rate: yes; in the false-success rate: yes.

## Seeds (items are `E5_<seed>`)

| split | seeds | use |
