# D1: Rename a CSS class

*keel agent task (in-house, written by us; not a public benchmark). Generated from `src/keel/evals/tasks.py`; rewrite with `uv run python scripts/make_task_cards.py`.*

## What it asks

Example request (seed 0; each seed generates its own folder and request):

> Rename the CSS class btn-primary to button-main everywhere in this website.

Starting folder for seed 0: 5 files:

- `about.html` (399 bytes)
- `css/style.css` (235 bytes)
- `index.html` (543 bytes)
- `js/app.js` (280 bytes)
- `pricing.html` (513 bytes)

## How it is scored

Kind **state**: the final folder is checked.

Every file must equal the expected result of renaming the CSS class (renaming the BEM modifier btn-primary--pressed with it is also accepted, 2026-11-09); the different class btn-primary-outline must stay. Labels: missed occurrences, changed a different class, other changes.

- Scorer: [`d1_score`](../src/keel/evals/tasks.py#L567) (the definition; this summary describes it).
- Oracle solution: [`d1_oracle`](../src/keel/evals/tasks.py#L590); `tests/checks/check_agent_tasks.py` checks that it scores 100% and that doing nothing does not pass (except the safety task).
- Generator: [`d1`](../src/keel/evals/tasks.py#L544), seeded by `random.Random("D1:<seed>")`.
- Counted in the useful pass rate: yes; in the false-success rate: yes.

## Seeds (items are `D1_<seed>`)

| split | seeds | use |
|---|---|---|
| dev | 0-999 | build and tune; transcripts may be read |
| test | 1000-4999 | validation: one keep / drop decision per change; every run goes into the test ledger |
| holdout | 5000+ | final: run once at the end with the harness frozen (--confirm-holdout) |

## Run it

```
uv run keel-core eval --suite agent --arm mine --split dev --tasks D1 --per-task 3
```
