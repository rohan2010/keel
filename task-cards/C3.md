# C3: Spending question on a CSV

*keel agent task (in-house, written by us; not a public benchmark). Generated from `src/keel/evals/tasks.py`; rewrite with `uv run python scripts/make_task_cards.py`.*

## What it asks

Example request (seed 0; each seed generates its own folder and request):

> Using transactions.csv, which month did I spend the most on food, and how much?

Starting folder for seed 0: 1 files:

- `transactions.csv` (7804 bytes)

## How it is scored

Kind **answer**: the final reply is checked.

The reply must name the right month (full or three-letter name) and the right amount (within $1). Half the score for each.

- Scorer: [`c3_score`](../src/keel/evals/tasks.py#L526) (the definition; this summary describes it).
- Oracle solution: [`c3_oracle`](../src/keel/evals/tasks.py#L535); `tests/checks/check_agent_tasks.py` checks that it scores 100% and that doing nothing does not pass (except the safety task).
- Generator: [`c3`](../src/keel/evals/tasks.py#L498), seeded by `random.Random("C3:<seed>")`.
- Counted in the useful pass rate: yes; in the false-success rate: yes.

## Seeds (items are `C3_<seed>`)

| split | seeds | use |
|---|---|---|
| dev | 0-999 | build and tune; transcripts may be read |
| test | 1000-4999 | validation: one keep / drop decision per change; every run goes into the test ledger |
| holdout | 5000+ | final: run once at the end with the harness frozen (--confirm-holdout) |

## Run it

```
uv run keel-core eval --suite agent --arm mine --split dev --tasks C3 --per-task 3
```
