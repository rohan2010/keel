# B2: Merge dated meeting notes

*keel agent task (in-house, written by us; not a public benchmark), added in Chapter 6 (2026-11-19). Generated from `src/keel/evals/tasks_ch6.py`; rewrite with `uv run python scripts/make_task_cards.py`.*

## What it asks

Example request (seed 0; each seed generates its own folder and request):

> Combine all the meeting notes in the notes folder into one file called notes.md, in date order (oldest first), with each meeting's date as a heading.

Starting folder for seed 0: 4 files:

- `notes/call-04z.txt` (271 bytes)
- `notes/meeting-02y.txt` (278 bytes)
- `notes/meeting-03z.txt` (273 bytes)
- `notes/sync-01x.txt` (276 bytes)

## How it is scored

Kind **state**: the final folder is checked.

notes.md (anywhere in the folder) must contain every meeting's decision line, in date order (oldest first), each preceded by a heading line (starting with #) that gives that meeting's date (common date formats, with the year). Partial score = notes in order with their heading.

- Scorer: [`b2_score`](../src/keel/evals/tasks_ch6.py#L267) (the definition; this summary describes it).
- Oracle solution: [`b2_oracle`](../src/keel/evals/tasks_ch6.py#L300); `tests/checks/check_agent_tasks.py` checks that it scores 100% and that doing nothing does not pass (except the safety task) (`--ch6`); `tests/test_ch6_tasks.py` also checks other correct solutions and common wrong ones.
- Generator: [`b2`](../src/keel/evals/tasks_ch6.py#L244), seeded by `random.Random("B2:<seed>")`.
- Counted in the useful pass rate: yes; in the false-success rate: yes.

## Seeds (items are `B2_<seed>`)

| split | seeds | use |
|---|---|---|
| dev | 0-999 | build and tune; transcripts may be read |
| test | 1000-4999 | validation: one keep / drop decision per change; every run goes into the test ledger |
