## How it is scored

Kind **answer**: the final reply is checked.

The reply must name the right file and its date (common date formats accepted). Half the score for each. Labels: wrong or missing file / date.

- Scorer: [`a3_score`](../src/keel/evals/tasks.py#L257) (the definition; this summary describes it).
- Oracle solution: [`a3_oracle`](../src/keel/evals/tasks.py#L264); `tests/checks/check_agent_tasks.py` checks that it scores 100% and that doing nothing does not pass (except the safety task).
- Generator: [`a3`](../src/keel/evals/tasks.py#L237), seeded by `random.Random("A3:<seed>")`.
- Counted in the useful pass rate: yes; in the false-success rate: yes.
