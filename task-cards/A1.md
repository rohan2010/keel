## How it is scored

Kind **state**: the final folder is checked.

Every generated file must end up, unchanged (matched by content hash), exactly one folder deep in the folder of its category. Partial score = share of files in the right place. Labels: lost files, wrong folder.

- Scorer: [`a1_score`](../src/keel/evals/tasks.py#L196) (the definition; this summary describes it).
- Oracle solution: [`a1_oracle`](../src/keel/evals/tasks.py#L215); `tests/checks/check_agent_tasks.py` checks that it scores 100% and that doing nothing does not pass (except the safety task).
- Generator: [`a1`](../src/keel/evals/tasks.py#L181), seeded by `random.Random("A1:<seed>")`.
- Counted in the useful pass rate: yes; in the false-success rate: yes.
