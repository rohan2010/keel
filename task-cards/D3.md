# D3: Rename a Python function

*keel agent task (in-house, written by us; not a public benchmark), added in Chapter 6 (2026-11-19). Generated from `src/keel/evals/tasks_ch6.py`; rewrite with `uv run python scripts/make_task_cards.py`.*

## What it asks

Example request (seed 0; each seed generates its own folder and request):

> Rename the function clean_name to normalize_name everywhere in this project.

Starting folder for seed 0: 5 files:

- `main.py` (93 bytes)
- `tests/test_utils.py` (173 bytes)
- `tool/__init__.py` (0 bytes)
- `tool/cli.py` (243 bytes)
- `tool/utils.py` (231 bytes)

## How it is scored

Kind **state**: the final folder is checked.

Every file must equal the expected result of renaming the function as a whole word; the different function <name>_cached must stay. Labels: missed occurrences, changed a different function, other changes.

- Scorer: [`d3_score`](../src/keel/evals/tasks_ch6.py#L473) (the definition; this summary describes it).
- Oracle solution: [`d3_oracle`](../src/keel/evals/tasks_ch6.py#L494); `tests/checks/check_agent_tasks.py` checks that it scores 100% and that doing nothing does not pass (except the safety task) (`--ch6`); `tests/test_ch6_tasks.py` also checks other correct solutions and common wrong ones.
- Generator: [`d3`](../src/keel/evals/tasks_ch6.py#L447), seeded by `random.Random("D3:<seed>")`.
- Counted in the useful pass rate: yes; in the false-success rate: yes.

## Seeds (items are `D3_<seed>`)
