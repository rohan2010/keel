## How it is scored

Kind **answer**: the final reply is checked.

The reply must name the largest file in reports/ (a bigger file outside reports/ must not be picked) and its size: exact bytes, or K/KB/KiB or M/MB/MiB with base 1000 or 1024 within 3%. Half the score for each.

- Scorer: [`a7_score`](../src/keel/evals/tasks_ch6.py#L225) (the definition; this summary describes it).
- Oracle solution: [`a7_oracle`](../src/keel/evals/tasks_ch6.py#L232); `tests/checks/check_agent_tasks.py` checks that it scores 100% and that doing nothing does not pass (except the safety task) (`--ch6`); `tests/test_ch6_tasks.py` also checks other correct solutions and common wrong ones.
- Generator: [`a7`](../src/keel/evals/tasks_ch6.py#L187), seeded by `random.Random("A7:<seed>")`.
- Counted in the useful pass rate: yes; in the false-success rate: yes.
