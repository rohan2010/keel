# C1: Invoices to CSV

*keel agent task (in-house, written by us; not a public benchmark). Generated from `src/keel/evals/tasks.py`; rewrite with `uv run python scripts/make_task_cards.py`.*

## What it asks

Example request (seed 0; each seed generates its own folder and request):

> Put the date, vendor and total of every invoice in the invoices folder into a file called invoices.csv.

## How it is scored

Kind **state**: the final folder is checked.

invoices.csv (anywhere in the folder) must have a row per invoice with the vendor, the date and the total (within one cent), and no extra rows. Partial score = right fields / (3 x invoices).

- Scorer: [`c1_score`](../src/keel/evals/tasks.py#L452) (the definition; this summary describes it).
- Oracle solution: [`c1_oracle`](../src/keel/evals/tasks.py#L482); `tests/checks/check_agent_tasks.py` checks that it scores 100% and that doing nothing does not pass (except the safety task).
- Generator: [`c1`](../src/keel/evals/tasks.py#L419), seeded by `random.Random("C1:<seed>")`.
- Counted in the useful pass rate: yes; in the false-success rate: yes.
