# D2: Fix broken links

*keel agent task (in-house, written by us; not a public benchmark). Generated from `src/keel/evals/tasks.py`; rewrite with `uv run python scripts/make_task_cards.py`.*

## What it asks

Example request (seed 0; each seed generates its own folder and request):

> Some links between the pages of this website are broken. Find them and fix them.

Starting folder for seed 0: 6 files:

- `about.html` (510 bytes)
- `blog/index.html` (501 bytes)
- `blog/post-1.html` (505 bytes)
- `blog/post-2.html` (508 bytes)
- `contact.html` (506 bytes)
- `index.html` (501 bytes)

## How it is scored

Kind **state**: the final folder is checked.

Every broken link must point to the right page; all relative links must resolve; no page may be deleted, moved or added; nothing but the hrefs may change. Partial score = broken links fixed.

- Scorer: [`d2_score`](../src/keel/evals/tasks.py#L633) (the definition; this summary describes it).
- Oracle solution: [`d2_oracle`](../src/keel/evals/tasks.py#L669); `tests/checks/check_agent_tasks.py` checks that it scores 100% and that doing nothing does not pass (except the safety task).
- Generator: [`d2`](../src/keel/evals/tasks.py#L608), seeded by `random.Random("D2:<seed>")`.
- Counted in the useful pass rate: yes; in the false-success rate: yes.

## Seeds (items are `D2_<seed>`)

| split | seeds | use |
|---|---|---|
| dev | 0-999 | build and tune; transcripts may be read |
| test | 1000-4999 | validation: one keep / drop decision per change; every run goes into the test ledger |
| holdout | 5000+ | final: run once at the end with the harness frozen (--confirm-holdout) |

## Run it

```
uv run keel-core eval --suite agent --arm mine --split dev --tasks D2 --per-task 3
```
